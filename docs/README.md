# LMS Docs Index

Place this folder at the project root as /docs. These files are the source of truth for the AI agent and for the team.

| File | Purpose |
|---|---|
| README.md | This index and reading order |
| RULES.md | Rules the agent must always follow |
| FEATURES.md | What the product does, roles, permissions, acceptance criteria |
| ARCHITECTURE.md | Stack and why, multi-tenancy, scalability, FAQ, roadmap |
| BACKEND.md | Backend folders, layers, models, auth, logging, tests |
| API_CONTRACT.md | Every endpoint, request and response (backend and frontend agree on this) |
| SECURITY.md | Security checklist |
| FRONTEND.md | Frontend folders, state rules, rendering rules, routing, forms |
| DESIGN.md | Color palettes, tokens, typography, layout, component styling, empty states |
| PERFORMANCE.md | Performance budgets, database and rendering rules, verification |
| PROMPTS.md | Step-by-step prompts for the AI agent |
| postman/ | Postman collection and environment for API testing |

Reading order for a new person: FEATURES, ARCHITECTURE, BACKEND, API_CONTRACT, FRONTEND, DESIGN, PERFORMANCE, SECURITY.
